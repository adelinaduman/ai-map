# The AI Map

An interactive map of the key AI models, tools and products in three layers (models, tools, agents), with side-by-side comparisons, a two-choice decision flow, pricing, and dated sources for recent changes. Built to help people decide which tool they actually need.

Live: https://adelinaduman.github.io/ai-map/

One self-contained HTML file, no build step. By Adelina Duman.
